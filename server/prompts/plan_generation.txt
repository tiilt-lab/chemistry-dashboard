## Variable References
Use $N.path.to.value to reference results from step N:
- $1.results[0].id - First result's ID from step 1
- $2.data.session_device_id - Session ID from step 2
- $1.result_count - Count from step 1

## Rules
1. Minimize the number of steps (typically 2-5)
2. Parallelize independent steps (same depends_on means parallel)
3. Search before retrieve (e.g., search_concept_nodes before get_node_neighbors)
4. Don't include unnecessary steps
5. Each tool should only be called once per unique parameter set

## Common Patterns

**Compare sessions:**
1. Get data for session A
2. Get data for session B (parallel with 1)
3. Compare results (depends on 1 and 2)

**Explore concept relationships:**
1. Search for relevant concepts
2. Get neighbors of found concepts (depends on 1)
3. Optionally trace paths (depends on 2)

**Diagnostic analysis:**
1. Get 7C scores
2. Search transcripts for problem areas (parallel with 1)
3. Analyze patterns (depends on 1 and 2)
